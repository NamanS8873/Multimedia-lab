# Multimedia-lab
Task 1 — Image Analyser
Libraries :
•OpenCV (cv2) — image processing (edge detection, color conversion, k-means)
•Pillow (PIL) — reading basic image metadata (format, mode, size)
•NumPy — numerical operations on pixel arrays
•Matplotlib — plotting the histogram

Task 2 — Video Analyser
Libraries :
•OpenCV (cv2) — reading video frame by frame, computing frame differences
•NumPy — averaging/array math per frame
•Matplotlib — plotting brightness and motion over time

Task 3 — Audio Analyser
Libraries :
•SciPy (scipy.io.wavfile, scipy.signal) — reading the WAV file and generating a spectrogram
•NumPy — signal math (RMS, zero-crossings)
•Matplotlib — plotting waveform and spectrogram
